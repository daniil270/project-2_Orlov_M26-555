# Примитивная база данных 

Учебный проект: консольная база данных с поддержкой CRUD-операций и сохранением в JSON.

## Запуск

```bash
database
```
## CRUD-операции

База данных поддерживает полный набор операций для работы с данными:

*   `<command> insert into <имя_таблицы> values (<значение1>, <значение2>, ...)` — создать новую запись.
*   `<command> select from <имя_таблицы>` — прочитать все записи из таблицы.
*   `<command> select from <имя_таблицы> where <столбец> = <значение>` — прочитать записи по условию.
*   `<command> update <имя_таблицы> set <столбец1> = <новое_значение> where <столбец_условия> = <значение>` — обновить существующие записи.
*   `<command> delete from <имя_таблицы> where <столбец> = <значение>` — удалить записи по условию.
